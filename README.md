# Xandra Hope

نظام تدريب موزّع لـ HEPL (Hybrid Expert-Parallel Learning) على معمارية Qwen2.5-Coder-1.5B-Instruct. يجمع بين Kaggle (GPU T4)، Hugging Face Hub، و GitHub Actions في منسّق آلي يدير ستة حسابات Kaggle ويرفع checkpoints إلى HF Hub.

## الوثائق

- [TRAINING_GUIDE.md](TRAINING_GUIDE.md) — دليل التدريب الكامل (المراحل، الإعدادات، استكشاف الأخطاء)
- [TEACHERS_AND_GOALS.md](TEACHERS_AND_GOALS.md) — المعلمون والأهداف التعليمية للنموذج
