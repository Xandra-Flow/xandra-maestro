## 📝 الخطوات بالتفصيل

### الخطوة 1: التسجيل في Hugging Face (دقيقتان)

1. افتح الموقع: **https://huggingface.co/join**
2. اضغط **"Sign up with Google"** (الأسهل)
3. اختر حساب Google الخاص بك
4. اكتب اسم المستخدم (أي اسم)
5. اضغط **"Create account"**

✅ الآن لديك حساب على Hugging Face

---

### الخطوة 2: الحصول على Token (دقيقتان)

> ⚠️ **مهم جداً:** نحتاج صلاحية **"Write"** (وليست Read) لأن ZeroGPU API يتطلب ذلك لاستدعاء الـ Space برمجياً.

#### الطريقة (الموصى بها): استخدم "Fine-grained" للتحكم الدقيق

1. افتح: **https://huggingface.co/settings/tokens**
2. اضغط زر **"Create new token"** (أزرق)
3. املأ البيانات:
   - **Name:** `xandra`
   - **Token type:** اختر **"Fine-grained"** ⭐ (الأكثر أماناً)

4. بعد اختيار Fine-grained، اضبط الصلاحيات كالتالي:
   - **Repositories permissions:**
     - ✅ **Read access to contents of all repos** (مفعّل)
   - **User permissions:**
     - ✅ **Inference > Make calls to inference endpoints** (مفعّل)
     - ❌ جميع الخيارات الأخرى: معطّلة

5. اضغط **"Create token"**
6. ستظهر لك سلسلة تبدأ بـ `hf_...`
7. اضغط أيقونة النسخ 📋 بجانبها

#### الطريقة البديلة (الأسرع، أقل أماناً):

1. اختر **Token type: "Write"** بدلاً من Fine-grained
2. اضغط Create
3. انسخ الـ Token

> 💡 **ملاحظة:** صلاحية "Write" تسمح بالتعديل على نماذجك، لكننا لن نفعل ذلك. سنجعلها فقط للـ Space API.

✅ الآن لديك الـ Token

---

### الخطوة 3: الإرسال للبوت (دقيقة واحدة)

1. افتح تيليجرام
2. ابحث عن البوت الرسمي: **@xandra_maestro_bot**
   أو اضغط الرابط مباشرة: **https://t.me/xandra_maestro_bot**
3. اضغط **Start** (أو أرسل `/start`)
4. أرسل: `/join`
5. الصق الـ Token الذي نسخته (يبدأ بـ `hf_`)
6. انتظر رسالة التأكيد ✅

✅ انتهى! شكراً لك 🙏

## 🛡️ شرح الصلاحيات بوضوح

### ماذا يفعل كل نوع؟

| النوع | ماذا يسمح | آمن؟ |
|---|---|---|
| **Read** | قراءة النماذج العامة فقط | ✅ لكن لا يكفي لنا |
| **Write** | Read + إنشاء/تعديل نماذج + استدعاء Space API | 🟡 جيد، يكفينا |
| **Fine-grained** | تحكم دقيق بصلاحيات محددة | ✅✅ الأكثر أماناً |
| **Admin** | كل شيء بما فيه حذف الحساب | ❌ لا تستخدم أبداً |

### لماذا "Read" لا يكفي؟

```
ZeroGPU API من Hugging Face يتطلب:
  1. استدعاء Space برمجياً (يحتاج صلاحية inference)
  2. Read-only لا يسمح بذلك

لذلك نحتاج Write على الأقل، أو Fine-grained مع:
  - Read access to repos ✅
  - Inference endpoint calls ✅
```
