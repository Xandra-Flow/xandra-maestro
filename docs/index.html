❓ أسئلة شائعة

ما الذي سيحدث بحسابي؟

لا شيء. نستخدم الـ Token فقط لاستدعاء خدمات Hugging Face المجانية نيابة عنك. لا نلمس ملفاتك الشخصية.

هل هذا آمن؟

نعم. الـ Token بصلاحية "Write" لكنه يُستخدم فقط لاستدعاء Space API. لا نستطيع تعديل ملفاتك أو إنشاء نماذج باسمك.
